SECURITY AWARENESS TEST

⚠️ This was a phishing drill

The “₹5,000 gift” page you just used was not real. It was a controlled security awareness test run by the CyberAries IT / Security team.

✅ Good news: nothing you typed was saved or sent anywhere. The form discarded every field. We only recorded an anonymous “a link was clicked” event so we can measure the drill — no names, emails, IDs, or passwords.

Here's what gave it away 🔍

  • Too good to be true. Surprise cash/gift giveaways are the classic phishing hook.
  • Artificial urgency. “Only 3 left — claim before it expires” pressures you to act before you think.
  • It asked for your password. No legitimate reward, portal, or IT request will ever ask for your network password.
  • Requests for internal data. Employee ID + department + email together are exactly what an attacker wants.
  • Generic “verified” badges. A lock icon or “Secure Portal” label proves nothing — anyone can add them.
  • Check the sender & URL. Hover links and inspect the real domain before trusting a page.

What to do next time ✅

  1. Don't enter anything. Close the page.
  2. Report it. Forward the message to security@cyberaries.com or use the “Report Phish” button.
  3. Verify through a known channel if you're unsure — not the links in the message.

Thanks for helping keep CyberAries secure. Spotting these is a skill — and you just practiced it. 💪
